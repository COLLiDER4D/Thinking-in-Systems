# Thinking in Systems

A collection of simulations exploring core concepts from **systems thinking** — stocks, flows, feedback loops, delays, and emergent behavior — implemented in Python. This repository serves as a hands-on companion for building intuition about how dynamic systems behave over time.

## About

Inspired by systems thinking literature (e.g., Donella Meadows' *Thinking in Systems*), this project translates classic systems-thinking models into interactive, code-based simulations. Each simulation lives in its own module and can be run, configured, and extended independently.
